📝 Ouvrir Notes 📁 Ouvrir Fichiers

  1. Notes : nouvelle note → 📎 (ou 📷) → Scanner des documents → Enregistrer. Touche le scan → Partager → {{ nom }}.
  2. Fichiers : ••• en haut → Scanner des documents → Enregistrer. Appui long sur le PDF → Partager → {{ nom }}.

Marche aussi avec une photo de la Photothèque ou un PDF reçu par mail : Partager → {{ nom }}. Tu peux ensuite supprimer la note ou le fichier : Claunote garde sa copie.

2. Créer le raccourci (une fois, 2 min)

  1. App Raccourcis → + → nomme-le {{ nom }}.
  2. Touche ⓘ en bas → active Afficher dans la feuille de partage. En haut du raccourci, la ligne « Recevoir … de Feuille de partage » apparaît : garde PDF, Images et Fichiers.
  3. Ajoute l'action Répéter avec chaque élément (sur « Entrée du raccourci »).
  4. Dedans, ajoute Obtenir le contenu de l'URL :
    • URL : {{ adresse }}
    • Touche › (Afficher plus) → Méthode : POST
    • En-têtes → Ajouter : clé Authorization, valeur {% if jeton %}ton jeton copié plus haut (« Bearer … »){% else %}Bearer + ton jeton (crée-le à l'étape 1){% endif %}
    • Corps de la requête : Fichier → Élément répété
  5. Toujours dans la boucle : Afficher la notification avec « Contenu de l'URL ». Tu verras « ✅ 1 scan envoyé à Claunote ».

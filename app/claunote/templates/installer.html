Claunote sur ton iPhone

Gratuit, sans App Store : Claunote s'installe comme une appli web. Il faut le VPN allumé (ou être sur le même réseau) pour l'ouvrir, mais les notifications arrivent partout.

{% if not adresse %}

⚠️ HTTPS n'est pas encore configuré sur le serveur : renseigne CLAUNOTE_HOTE dans le .env (voir infra/SETUP.md, section 13), puis docker compose up -d.

{% endif %}
  1. Installer le certificat de Claunote

    Il permet à l'iPhone de faire confiance à ton serveur (HTTPS sans nom de domaine payant).

    {% if certificat %}Télécharger le certificat {% else %}

    Certificat pas encore créé : le service caddy doit avoir démarré.

    {% endif %}

    Puis Réglages → Profil téléchargé → Installer (code de l'iPhone).

  2. Lui faire confiance

    Réglages → Général → Informations → Réglages des certificats (tout en bas) → active Claunote.

  3. Ouvrir Claunote en HTTPS dans Safari {% if adresse %}

    {{ adresse }}

    {% endif %}

    Pas d'avertissement de sécurité ? Le certificat est bon.

  4. L'ajouter à l'écran d'accueil

    Bouton Partager → Sur l'écran d'accueil → laisse Ouvrir en tant qu'app web activé → Ajouter.

  5. Activer les notifications

    Ouvre Claunote depuis son icône, puis Plus → Notifications → Activer et accepte. Touche Envoyer un test pour vérifier.
